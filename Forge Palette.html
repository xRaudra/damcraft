05 — When to Use Each Color

→
CTAs · Links · Accents

Forge — The Brand Color

Use for buttons, active nav states, hover underlines, pull quotes, and the logo mark on dark backgrounds. Never use as a body text color — too vivid to read at length.

→
Tags · Hover · Tints

Ember — Supporting Warm

Use for category tags, hover state fills, icon colors on dark sections, and background tints behind orange content. Bridges Forge down to the neutral palette.

→
Headings · Dark sections

Pitch — The Anchor Dark

Use for all headings, dark hero sections, footers, and anywhere Forge needs a dramatic backdrop. Warm near-black — intentionally not pure #000 to feel crafted, not printed.
