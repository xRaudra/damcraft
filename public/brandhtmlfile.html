Vertical alignment: Align the wordmark's optical centre to 45% from the top of the mark — not the geometric midpoint. The dome is visually heavy at the top; centering on 50% makes the wordmark appear dropped.

Logo Don'ts

Don't recolor

Only Pitch, Chalk, or Forge — no greys, gradients, or custom tints

Don't rotate

Arch always upright — base at the bottom, never angled

Don't distort

Scale proportionally — stretching destroys the arch geometry

Don't clash

Never place Forge mark on competing saturated colors

Logo Treatments

Foot Mask

The mark fades into the surface at its base — as if cast into the material rather than placed on top of it. Used on large-format print, environmental signage, and full-bleed hero sections where the logo anchors into the background.

Morphs

Lockup variations for different contexts — the same mark adapts its arrangement without changing its form. Use the primary stacked lockup by default; reach for the horizontal or mark-only variants when space or context demands it.

Spacing

The exclusion zone defines the minimum clear space that must surround the logo at all times. Nothing — text, imagery, or other marks — may enter this protected area. The unit (1×) equals the height of one DAM letter cutout.

1× clear space 1× clear space 1× 1×

The dashed boundary marks the minimum exclusion zone — no other elements inside.

Photo Contrast

The logo must remain legible across all photographic contexts. On light imagery use the Pitch version; on dark or mid-tone imagery use Forge orange or Chalk white. Never use a tint or drop shadow to compensate for poor contrast — choose the correct logo variant.

Dark imagery · Forge

Do / Don't

✓ Arch mark only

Use the arch mark alone. The full logotype with CRAFT wordmark is illegible at icon sizes.

✓ Export flat square

Export a flat 1024×1024 PNG. iOS and Android apply platform shapes automatically.

✕ No drop shadows

Do not add drop shadows, glows, or outer strokes. The OS handles icon elevation.

✕ Approved colours only

Only use Chalk, Pitch, or Forge Fire backgrounds. Do not invent new tints or colours.

13

Shadows

Damcraft shadows are warm — cast from Pitch, not cold black. Every elevation layer uses rgba(26,14,8,…) to maintain depth within the brand's earthy register.

Elevation Scale

E–0 Flat box-shadow: none Inputs · table rows · flush content
E–1 Lifted 0 1px 3px rgba(26,14,8,.07), 0 1px 2px rgba(26,14,8,.05) Page cards · tags · chips
E–2 Raised 0 4px 12px rgba(26,14,8,.10), 0 2px 4px rgba(26,14,8,.06) Dropdowns · tooltips · hover cards
E–3 Floating 0 10px 28px rgba(26,14,8,.13), 0 4px 8px rgba(26,14,8,.07) Modals · command palette · sticky nav
E–4 Elevated 0 20px 48px rgba(26,14,8,.18), 0 8px 16px rgba(26,14,8,.09) Side drawers · bottom sheets · panels
E–5 Dominant 0 40px 80px rgba(26,14,8,.22), 0 16px 32px rgba(26,14,8,.11) Hero brand cards · oversized features

0 8px 24px rgba(255,83,0,.32),
0 3px 8px rgba(255,83,0,.18)

Reserved for primary CTA buttons only. Signals the highest-priority action on the page — use once per screen maximum.

Inset · Pressed

inset 0 2px 8px rgba(26,14,8,.20)

Applied on :active / pressed state. Gives interactive elements a physical "pushed in" sensation on click or tap.

Surface Highlight

inset 0 1px 0 rgba(255,255,255,.9),
0 4px 12px rgba(26,14,8,.10)

Inner top highlight paired with a soft drop shadow. Used on raised surface cards to suggest material thickness and light from above.

When to Use Each Level

E–0 · Flat

Embedded

Form inputs · table rows · inline badges · content visually flush with its parent surface

E–1 · Lifted

Surface Cards

Content cards on page · image frames · tag chips · subtle separation from background

E–2 · Raised

Interactive UI

Dropdowns · tooltips · hover cards · date pickers · context menus

E–3 · Floating

Overlay Layer

Modals · command palette · sticky navigation · full-width announcement bars

E–4 · Elevated

Panels & Sheets

Side drawers · bottom sheets · full-panel overlays · persistent sidebars

E–5 · Dominant

Hero Moments

Brand hero cards · oversized feature elements · key promotional components that must visually lead the page

Do / Don't

✓ Warm tint

Use rgba(26,14,8,…) — the Pitch shadow keeps depth earthy and on-brand

✕ Cold black

Never use pure rgba(0,0,0,…) — reads cold and grey, breaks the warm brand register

✓ Step up on hover

Raise one level on hover (E2→E3). Hover the card above to see it — deliberate, not dramatic

✕ No stacking

Never combine multiple elevation levels on one element — choose one level and commit to it
